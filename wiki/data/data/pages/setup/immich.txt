====== Immich — Photo Management ======

**Prerequisite:** [[setup:traefik|Traefik & dnsmasq]] running.

----

===== What Immich Provides =====

Immich is a self-hosted photo and video management platform.  This deployment includes:

  * A web UI at ''http:%%//%%immich.local'' for browsing, searching, and organising photos.
  * Automatic mobile backup via the Immich iOS/Android app over the local network.
  * A machine-learning container that runs face recognition and CLIP-based smart search.
  * A Postgres database with the ''pgvecto.rs'' extension for vector similarity search.
  * Redis for job queuing and caching.

----

===== Container Architecture =====

Immich consists of four containers that work together:

^ Container                  ^ Role                                              ^
| ''immich-server''          | Main API + web UI                                 |
| ''immich-machine-learning'' | AI model inference (face recognition, CLIP)      |
| ''immich-db''              | Postgres 14 with pgvecto.rs + pgvectors extensions |
| ''immich-redis''           | Job queue and cache                               |

''immich-server'' is the only container that joins the ''proxy'' network (Traefik-visible).  All others are on ''internal'' only.

===== Step-by-Step Deployment =====

==== Step 1: Prepare .env ====

<code>
cp immich/.env.example immich/.env
nano immich/.env
</code>

<code>
# Path on the VM where uploaded photos are stored
UPLOAD_LOCATION=./photos

# Database credentials
DB_USERNAME=immich
DB_PASSWORD=changeme_strong_password
DB_DATABASE_NAME=immich
</code>

==== Step 2: Create the photos directory ====

<code>
mkdir -p immich/photos
</code>

==== Step 3: Start the stack ====

<code>
docker compose -f immich/docker-compose.yml up -d
</code>

Docker Compose starts containers in this order (enforced by healthchecks):
  - ''immich-redis'' and ''immich-db'' start in parallel.
  - Once both pass their healthchecks, ''immich-server'' starts.
  - ''immich-machine-learning'' starts independently (no healthcheck dependency).

==== Step 4: Verify ====

<code>
docker compose -f immich/docker-compose.yml ps
# immich-db and immich-redis should show "(healthy)"
# immich-server should show "Up"
</code>

<code>
docker logs immich-server --tail 30
# Should show: "Immich Server is listening on..."
</code>

==== Step 5: Create the admin account ====

  - Open ''http:%%//%%immich.local'' in a browser.
  - The first-run page appears: enter an email address and password for the admin account.
  - Click **Create Account**.

==== Step 6: Configure the mobile app ====

  - Install the [[https://immich.app/docs/features/mobile-app|Immich mobile app]] on iOS or Android.
  - Open the app → **Settings** → **Server URL**: enter ''http:%%//%%immich.local''
  - Log in with the admin credentials.
  - Enable **Background backup** in app settings to sync photos automatically when on the home Wi-Fi.

> **Note:** The mobile device must be on the same network as the VM (or connected via the same router that the host is on) for ''immich.local'' to resolve.

===== Healthcheck Details =====

Both ''immich-db'' and ''immich-redis'' have healthchecks:

<code>
# immich-db
healthcheck:
  test: ["CMD-SHELL", "pg_isready -U $$POSTGRES_USER -d $$POSTGRES_DB"]
  interval: 10s
  timeout: 5s
  retries: 5

# immich-redis
healthcheck:
  test: ["CMD", "redis-cli", "ping"]
  interval: 10s
  timeout: 5s
  retries: 5
</code>

''immich-server'' has ''depends_on: condition: service_healthy'' for both, so it will not attempt a database connection until both backends are ready.

----

===== Database Note =====

Immich requires Postgres with the ''pgvecto.rs'' and ''pgvectors'' extensions for vector similarity search (used by smart photo search and face recognition).  The image used is:

''ghcr.io/immich-app/postgres:14-vectorchord0.3.0-pgvectors0.2.0''

This is maintained by the Immich project and is the only officially supported database image.  Do not substitute a plain Postgres image — the extensions will be missing and Immich will fail to start.

----

===== Updating Immich =====

Immich releases frequently.  To update, change **both** the server and ML image tags to the same version:

<code>
# docker-compose.yml
immich-server:
  image: ghcr.io/immich-app/immich-server:v1.118.0   # updated

immich-machine-learning:
  image: ghcr.io/immich-app/immich-machine-learning:v1.118.0  # must match
</code>

<code>
docker compose -f immich/docker-compose.yml pull
docker compose -f immich/docker-compose.yml up -d
</code>

Check [[https://github.com/immich-app/immich/releases|Immich releases]] for breaking changes before updating.

===== Troubleshooting =====

^ Symptom                              ^ Likely Cause                          ^ Fix                                              ^
| ''http:%%//%%immich.local'' not loading  | immich-server not running             | ''docker logs immich-server''                    |
| "Database connection refused"         | immich-db healthcheck failing         | ''docker logs immich-db''                        |
| Mobile app cannot connect            | Device not on same LAN / DNS issue    | Confirm device can resolve ''immich.local''      |
| Face recognition not working          | ML container not running              | ''docker compose ... up -d'' restarts all        |
| Slow / no thumbnails                 | immich-server still processing        | Wait a few minutes; check ''docker logs''        |
